# Daily Log — документация

Версия 2.0 (в разработке, макет — в `МАКЕТ.md`). Приложение для ведения пищевого дневника с фокусом на наблюдение за поведением, а не на подсчёт калорий.

## Назначение

- Фиксировать приёмы пищи: голод до еды (1–10), сытость после, контекст (скука, стресс, слинг и т.п.), заметка.
- Быстро записывать эмоции и ощущения между приёмами пищи.
- Видеть таймер: сколько прошло с подъёма или с последнего приёма пищи.
- Держать перед глазами «фокус недели» — один приоритет в работе с пищевым поведением.
- Выгружать данные файлом (JSON/CSV) для анализа и резервного копирования.

Все данные хранятся только на телефоне пользователя (IndexedDB) и никуда не отправляются.

## Технологии

- Один статический сайт: HTML + CSS + ванильный JavaScript, без фреймворков и сборки.
- IndexedDB — пять хранилищ: `meals` (приёмы пищи), `notes` (быстрые записи), `days` (время подъёма по датам), `focus` (фокус недели), `weights` (вес и талия).
- localStorage — настройки: дефолтное время подъёма, текст «фокуса недели», дата последней копии.
- Service Worker (`sw.js`) — офлайн-режим: приложение открывается без интернета после первого запуска.
- `manifest.webmanifest` + иконки — установка на домашний экран iPhone как PWA.
- Лёгкая/тёмная тема (по настройкам системы).

## Структура файлов репозитория

| Файл | Назначение |
|---|---|
| `index.html` | Разметка: 4 вкладки, листы «Приём пищи», «Запись», «Подъём» |
| `style.css` | Стили (светлая/тёмная тема) |
| `app.js` | Вся логика: данные, рендер, таймер, экспорт/импорт |
| `sw.js` | Офлайн-кэш; при каждом обновлении файлов номер кэша поднимается |
| `manifest.webmanifest` | Манифест PWA |
| `icon-180.png`, `icon-192.png`, `icon-512.png` | Иконки |

## Экраны и поведение

### Вкладка «Сегодня»
Таймер (до первого приёма — от подъёма, после — от последнего приёма; крупное время, приглушённая подпись; обновление каждые 30 сек), карточка «Фокус недели» прямо под таймером (автосброс по понедельникам, каждая правка дублируется строкой 📌 во «Дневнике»), две большие кнопки («приём пищи» и «запись»), поле «Подъём» с редактированием, плитки статистики дня (число приёмов, средний голод до еды, средняя сытость после еды).

### Вкладка «Дневник»
Общая лента: приёмы пищи, быстрые записи и правки «Фокус недели» (📌) в хронологическом порядке, группировка по дням, фильтр «Все / Приёмы / Записи». Тап открывает лист редактирования — у записи меняются время и текст, у приёма пищи — все поля, 📌 ведёт на карточку фокуса.

### Вкладка «Динамика»
Вес и талия: последнее значение, разница с первой записью, график, форма добавления, удаление записей. Таблица «По дням»: подъём, число приёмов, средний голод до еды, средняя сытость после, доля осознанных приёмов; тап по строке открывает этот день во «Дневнике».

### Вкладка «Настройки»
Дефолтное время подъёма, резервная копия (JSON), выгрузка CSV, восстановление из копии, предупреждение о локальном хранении данных, номер версии.

## Форматы данных

### JSON (резервная копия)
```json
{
  "app": "daily-log",
  "version": 2,
  "exportedAt": "2026-11-24T...",
  "meals": [{"id", "ts", "before", "after", "mindful", "ctx", "note"}],
  "notes": [{"id", "ts", "text"}],
  "days":  [{"date", "wake"}],
  "focus": [{"week", "ts", "text"}],
  "weights": [{"id", "date", "kg", "waist"}]
}
```

`focus.week` — ключ недели (дата её понедельника), одна запись на неделю.

### CSV (для анализа)
Разделитель `;`, UTF-8 с BOM (открывается в Excel с русской локалью). Один файл, колонка «тип»: `подъём / приём / запись / фокус / вес`. Пустые ячейки — поле неприменимо к типу.

```
дата;время;тип;голод_до;сытость_после;осознанно;контекст;текст;кг;талия
2026-11-24;06:45;подъём;;;;;;;;
2026-11-24;08:15;приём;3;7;1;;;
2026-11-24;09:05;фокус;;;;;не ем соломку · в слинге чай · без осуждения;;
2026-11-24;12:05;приём;4;6;0;скука;;;
2026-11-24;12:30;запись;;;;;сижу с малышом в слинге, скучно, хочу пожевать;;;
2026-11-24;;вес;;;;;;;72,4;84
```

## Миграция с версии 1.0

База обновляется без удаления данных: добавляется хранилище `notes`, в `days` появляется поле `wake`, добавляется `focus`. Вес (`weights`) продолжает использоваться — теперь на вкладке «Динамика». Старые отметки дня (сон, настроение, энергия) остаются в базе, но не отображаются. Восстановление из старой копии JSON поддерживается: отметки дня просто игнорируются.

# Как выложить на GitHub

## Первый раз (создание репозитория и публикация)

1. Зайдите на **github.com** и войдите в аккаунт.
2. **New repository** (зелёная кнопка или «+» вверху справа).
3. Имя: `daily-log`. Видимость: **Public**. Ничего больше не отмечать → **Create repository**.
4. На странице пустого репозитория нажмите **uploading an existing file**.
5. Перетащите **все файлы** из папки `daily-log` (`index.html`, `app.js`, `style.css`, `sw.js`, `manifest.webmanifest`, `icon-180.png`, `icon-192.png`, `icon-512.png`) — не саму папку.
6. Внизу **Commit changes**.
7. **Settings** → слева **Pages** → Source: **Deploy from a branch** → Branch: **main**, папка **/ (root)** → **Save**.
8. Через 1–2 минуты на той же странице появится адрес вида `https://ВАШ-ЛОГИН.github.io/daily-log/`. Откройте его на компьютере и проверьте загрузку.

## Обновление приложения (когда код меняется)

1. На GitHub в репозитории: **Add file** → **Upload files** → перетащите изменённые файлы (имена должны совпадать) → **Commit changes**.
2. При изменении `sw.js`, `app.js`, `index.html` или `style.css` обязательно поднимите номер кэша в `sw.js` (строка `const CACHE = 'daily-log-vN'`) — иначе телефоны не скачают новую версию.
3. На iPhone: откройте приложение при включённом интернете (при необходимости с VPN), полностью закройте и откройте снова. Новая версия подхватится со второго запуска. Номер версии виден внизу «Настроек». Данные при обновлении не теряются.

## Проверка перед выкладкой (локально)

Откройте `index.html` в браузере двойным щелчком — приложение работает и с диска. Проверьте: запись приёма, быструю запись, таймер, экспорт CSV/JSON.

## Установка на iPhone (для себя)

1. Откройте адрес из п. 8 **в Safari** (не в другом браузере).
2. **Поделиться** (квадрат со стрелкой) → **На экран «Домой»** → **Добавить**.
3. Откройте приложение **с иконки** один раз при включённом интернете — оно сохранится для офлайна.
4. Проверка: включите авиарежим, закройте и откройте приложение с иконки — оно должно запуститься.

⚠️ Записывайте только через иконку. Во вкладке Safari у страницы отдельное хранилище: данные там и в установленном приложении не пересекаются.

## Резервная копия

Раз в неделю: «Настройки» → **Сохранить копию (JSON)** → сохранить в «Файлы» (iCloud Drive) или отправить себе в «Избранное» Telegram. Восстановление: «Настройки» → **Восстановить из копии**.

**Если удалить иконку с экрана «Домой», данные удалятся вместе с ней.**
