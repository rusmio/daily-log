# Daily Log: как запустить

В репозиторий загружается только содержимое папки `daily-log` (8 файлов). Этот файл и любые экспорты данных туда не кладём.

## 1. Загрузить на GitHub (~5 минут, с компьютера)

1. github.com → **New repository** (зелёная кнопка или «+» вверху справа).
2. Repository name: `daily-log`. Видимость: **Public**. Больше ничего не отмечать → **Create repository**.
3. На странице пустого репозитория нажать ссылку **uploading an existing file**.
4. Перетащить **файлы** из `C:\work\diet\daily-log` (не саму папку):
   `index.html`, `app.js`, `style.css`, `sw.js`, `manifest.webmanifest`, `icon-180.png`, `icon-192.png`, `icon-512.png`.
5. Внизу **Commit changes**.
6. **Settings** → слева **Pages** → Source: **Deploy from a branch** → Branch: **main**, папка **/ (root)** → **Save**.
7. Через 1–2 минуты на этой же странице появится адрес вида
   `https://ВАШ-ЛОГИН.github.io/daily-log/`. Откройте его на компьютере и проверьте, что страница загружается.

## 2. Установить на iPhone

1. Откройте адрес **в Safari**. Если не открывается, включите VPN, это нужно только сейчас.
2. Дождитесь полной загрузки страницы.
3. **Поделиться** (квадрат со стрелкой) → **На экран «Домой»** → **Добавить**.
4. Откройте приложение **с иконки**, один раз при включённом интернете, чтобы оно сохранилось для офлайна.
5. Проверка: включите авиарежим, закройте и снова откройте приложение с иконки. Оно должно запуститься.

⚠️ Записывайте только через иконку. Во вкладке Safari у страницы отдельное хранилище, данные там и в приложении не пересекаются.

## 3. Напоминания (по желанию)

Приложение «Команды» → **Автоматизация** → **+** → **Время суток** → например, 12:00, ежедневно → **Запускать сразу** → действие **Показать уведомление** с текстом вроде «Как голод? Отметь в Daily Log».
Повторите для 16:00 и 19:00, если нужно.

Действие «Открыть URL» не подходит: оно откроет Safari, а не установленное приложение.

## 4. Резервная копия раз в неделю

«Данные» → **Сохранить копию (JSON)** → сохранить в «Файлы» (iCloud Drive) или отправить себе в «Избранное» Telegram.
Восстановление: «Данные» → **Восстановить из копии** → выбрать файл.

**Если удалить иконку с экрана «Домой», данные удалятся вместе с ней.**

## 5. Ретро

Раз в неделю: «Данные» → **Выгрузить таблицу (CSV)** → прислать файл в чат с Claude для разбора закономерностей.

## 6. Обновления приложения

Когда код меняется:
1. На GitHub в репозитории: **Add file** → **Upload files** → перетащить изменённые файлы (с теми же именами) → **Commit changes**.
2. На iPhone откройте приложение при включённом интернете (при необходимости с VPN), полностью закройте его и откройте снова. Новая версия загрузится со второго запуска. Номер версии виден внизу вкладки «Данные».

Данные при обновлении не теряются.
