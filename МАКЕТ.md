# Daily Log 2.0 — макет

Четыре вкладки: **Сегодня · Дневник · Динамика · Настройки**.

Убираем: вкладку «Динамика», карточку «Как день», карточку «Спринт», плашку «Пора сделать резервную копию», блок «Что сохранено».
Добавляем: таймер (с подъёма / с последнего приёма), запись подъёма, быструю запись «эмоции, ощущения», карточку «Фокус недели», вкладку «Дневник», настройку дефолтного времени подъёма.

### Логика таймера

- **До первого приёма пищи** таймер считает от подъёма: «2:05 с подъёма».
- **После первого приёма** — от последнего приёма: «3:26 с последнего приёма пищи».
- Подпись под временем — мелким приглушённым текстом; акцент на самом времени.
- Подъём на плашке таймера **не показывается** — он вынесен в отдельное поле ниже кнопок.
- Подъём сегодня не записан → таймер до первого приёма считается от «подъёма по умолчанию» из Настроек, в поле подъёма пометка «по умолчанию».
- Сейчас раньше дефолтного подъёма и записи нет → вместо таймера «—», в поле подъёма кнопка «Записать».
- Таймер живой: обновление каждые 30 секунд (и при возврате в приложение).

### Лист «Подъём» (открывается тапом по полю «Подъём»)

```
┌─────────────────────────────────────┐
│ Подъём                     [Закрыть]│
│                                     │
│ Когда  [24.11.2026   06:45]         │  ← datetime, предзаполнен
│                                     │     дефолтом из Настроек
│                  [Сохранить]        │
└─────────────────────────────────────┘
```

Одно значение на день: повторная запись перезаписывает время подъёма.

### Лист «Запись» (эмоции, ощущения — вторая большая кнопка)

```
┌─────────────────────────────────────┐
│ Запись                     [Закрыть]│
│                                     │
│ Когда  [24.11.2026   12:30]         │
│                                     │
│ Текст                               │
│ ┌─────────────────────────────────┐ │
│ │ сижу с малышом в слинге, скучно,│ │
│ │ хочу пожевать. пью чай          │ │
│ └─────────────────────────────────┘ │
│                                     │
│ [Удалить]               [Сохранить] │
└─────────────────────────────────────┘
```

Только время + свободный текст. Никаких шкал и тегов — чтобы барьер записи был минимальным.
Тот же лист открывается при редактировании записи из вкладки «Дневник».

### Карточка «Фокус недели»

По тапу раскрывается текстовое поле (как лист «Запись», без времени): редактируешь → «Сохранить».

- **Автосброс по понедельникам**: хранится текст + ключ недели (дата её понедельника). В новую неделю карточка показывает пустое состояние «Какой фокус на этой неделе?» — текст прошлой недели автоматически не переносится.
- Одна запись фокуса на неделю: повторная правка в той же неделе обновляет текст.
- **Каждая правка фокуса отображается в «Дневнике»** строкой 📌 «Фокус недели: …» в день и время правки — там накапливается история фокусов.

## Вкладка «Дневник»

Все записи подряд: приёмы пищи и свободные записи, группировка по дням, свежие сверху.

```
┌─────────────────────────────────────┐
│ Дневник                       [Все▾]│  ← фильтр: Все / Приёмы / Записи
│                                     │
│ Сегодня, 24 ноября                  │
│   9:05  📌 Фокус недели: не ем      │
│            соломку · чай в слинге   │
│  12:30  ✎  сижу с малышом в слинге, │
│            скучно, хочу пожевать    │
│  12:05  🍽 голод 4 → 6 · скука      │
│   8:15  🍽 голод 3 → 7 · осознанно  │
│                                     │
│ Вчера, 23 ноября                    │
│  22:00  🍽 голод 2 → 8              │
│  21:18  ✎  хочу есть                │
│  ...                                │
└─────────────────────────────────────┘
[ Сегодня │ Дневник │ Динамика │ Настройки ]
```

- Тап по 🍽 → существующий лист приёма пищи (время, шкалы, теги, заметка).
- Тап по ✎ → лист «Запись» (можно поменять **время и текст**).
- Тап по 📌 → карточка «Фокус недели» на «Сегодня».
- Строка 📌 появляется в ленте при каждой правке фокуса (день и время правки). Под фильтрами «Приёмы» и «Записи» скрыта, под «Все» видна.
- Приём без оценки сытости помечен «оценить сытость» — тап → дооценить. Так сытость теперь дооценивается только здесь (блок «Оценить сытость» с «Сегодня» убран).
- Удаление — кнопкой внутри листа (как у приёмов сейчас).

```
┌─────────────────────────────────────┐
│ Динамика                            │
│ ┌─────────────────────────────────┐ │
│ │ Вес                             │ │
│ │  72,4 кг    −0,8 кг с 01.11     │ │
│ │  [график веса — как сейчас]     │ │
│ │                                 │ │
│ │  Дата [24.11] Вес [72,4]        │ │
│ │  Талия [84]        [Добавить]   │ │
│ │  24.11 · 72,4 кг · талия 84  ✕  │ │
│ └─────────────────────────────────┘ │
│ ┌─────────────────────────────────┐ │
│ │ По дням                         │ │
│ │ День   Подъём Прёмы Голод Сыт   │ │
│ │               до    после Осозн.│ │
│ │ 24.11 пн 6:45  4   3,8   6,3 2/4│ │
│ │ 23.11 вс 6:40  7   3,1   7,0 3/7│ │
│ │ 22.11 сб  —    6   3,3   6,8 2/6│ │
│ └─────────────────────────────────┘ │
└─────────────────────────────────────┘
[ Сегодня │ Дневник │ Динамика │ Настройки ]
```

- **Вес** — как в старой «Динамике»: последнее значение, разница с первой записью, график, форма добавления (дата, кг, талия), удаление последних записей.
- **По дням** — таблица: день, время подъёма, число приёмов, средний голод до еды, средняя сытость после, доля осознанных приёмов (2/4 — два из четырёх).
- Тап по строке таблицы → переход во «Дневник» на этот день.
- Дневные графики голода/сытости из старой версии **не переносим** — разбор закономерностей делаем по CSV.

## Что именно удаляется из версии 1.0

| Удалено | Куда делось |
|---|---|
| Дневные графики голода/сытости из «Динамики» | не переносятся — анализ по CSV |
| Карточка «Как день» (сон, настроение, энергия) | убрана целиком |
| Карточка «Спринт 1: наблюдение» | убрана (напоминания больше не нужны — есть «Фокус недели») |
| Плашка «Пора сделать резервную копию» + вся логика просрочки копии | убрана |
| Блок «Что сохранено» в «Данных» | убран |
| Блок «Оценить сытость» на «Сегодня» | убран — дооценка через «Дневник» (тап по приёму) |

Старые данные в базе при обновлении приложения не удаляются физически. Отметки дня (сон, настроение, энергия) перестают отображаться и не попадают в CSV — версия 2.0 их больше не собирает.

## Правки версии 2.1.0 (реализовано)

1. **Дневник: обратная хронология.** Самые свежие записи — сверху, в том числе внутри дня (сейчас дни идут новые сверху, а внутри дня — старые сверху).
2. **Упростить лист приёма пищи.** Убрать галочку «Ела осознанно» и теги контекста — вся информация пишется в поле «Заметка». Соответственно: убрать эти поля из карточек/ленты, плиток и CSV-экспорта (колонки `осознанно`, `контекст`), из JSON-структуры и из вкладки «Динамика» (колонка «Осозн.» в таблице по дням).
3. **Экспорт JSON: убрать лишнюю текстовую заметку.** Симптом уточнён: второй «файл» — заметка «Текст 5», внутри неё имя json-файла, а не данные. Причина: `navigator.share` вызывается с `title`, и если цель шаринга не принимает файлы, она получает `title` как текст → создаётся текстовая заметка. Дублей данных нет. Решение для реализации: убрать `title` из вызова `navigator.share` (передавать только `files`), плюс блокировать кнопки экспорта до завершения сохранения (защита от двойного нажатия — повторный клик давал бы «…(1).json»).

## Решённые вопросы (зафиксировано для реализации)

1. **Вес и талия** — отдельная вкладка «Динамика» + таблица приёмов пищи по дням. ✅
2. **Быстрая запись** — только свободный текст, без тегов и шкал. ✅
3. **CSV-выгрузка** — один файл с колонкой «тип» (`подъём / приём / запись / фокус / вес`), формат ниже. ✅
4. **«Фокус недели»** — автосброс по понедельникам, каждая правка видна в «Дневнике» строкой 📌. ✅

### Формат CSV (финальный)

Разделитель `;`, UTF-8 с BOM. Пустые ячейки — там, где поле неприменимо к типу.

```
дата;время;тип;голод_до;сытость_после;осознанно;контекст;текст;кг;талия
2026-11-24;06:45;подъём;;;;;;;;
2026-11-24;08:15;приём;3;7;1;;;
2026-11-24;09:05;фокус;;;;;не ем соломку · в слинге чай · без осуждения;;
2026-11-24;12:05;приём;4;6;0;скука;;;
2026-11-24;12:30;запись;;;;;сижу с малышом в слинге, скучно, хочу пожевать;;;
2026-11-24;;вес;;;;;;;72,4;84
```

Этого достаточно для анализа: интервалы между приёмами и от подъёма, голод/сытость по времени суток, контексты, текст заметок, динамика веса на фоне фокусов.
